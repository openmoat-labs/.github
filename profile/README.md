# OpenMoat lives at Crocodile Labs 🐊

**The official OpenMoat repository is [github.com/crocodile-labs/openmoat](https://github.com/crocodile-labs/openmoat).**

OpenMoat is a firewall and seatbelt for AI coding agents. One policy decides allow,
ask or deny for every tool call of Claude Code, Codex and Cursor, backed by OS sandboxes
and an egress proxy, with a tamper-evident audit log.

This organization only points the way. It hosts no code and publishes no releases.
Install OpenMoat only from [crocodile-labs/openmoat](https://github.com/crocodile-labs/openmoat)
and its releases.
